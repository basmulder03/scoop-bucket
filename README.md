# scoop-bucket

[Scoop](https://scoop.sh) bucket for [repo-keeper](https://github.com/basmulder03/repo-keeper).

```powershell
scoop bucket add repo-keeper https://github.com/basmulder03/scoop-bucket
scoop install repo-keeper
```

The manifest in `bucket/` is generated by repo-keeper's release process and copied here after each release. Issues belong in the [main repository](https://github.com/basmulder03/repo-keeper/issues).
